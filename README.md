## 📚 Course Overview

CPE 031 introduces the foundations of data analytics and visualization. It focuses on transforming data into meaningful insights through appropriate charts, visual design, dashboards, and responsible data communication.

The course also introduces big data management, artificial intelligence, machine learning, and career opportunities in data analytics.

### Prelim Period — Foundations of Data Analytics

- Introduction to the Course and Course Policies
- Experience Analytics: Understanding Data and Business Needs
- Data Collection and Storage
- Understanding Big Data and Big Data Management
- Artificial Intelligence and Machine Learning
- Career Opportunities in Data Analytics

### Midterm Period — Data Visualization and Design

- Selecting Appropriate Chart Types
- Data Visualization and Design Principles
- Purposeful Use of Color
- Visualizing Variability

### Final Period — Visual Communication and Dashboards

- Exploring Data Visually
- Explaining Visually to Influence with Data
- Data Dashboards
- Telling the Truth with Data Visualization

## 🎯 Course Learning Outcomes

This repository supports the development of skills in:

- Selecting suitable chart types based on data, message, and audience.
- Exploring and analyzing data to identify meaningful patterns.
- Creating visualizations and dashboards that communicate insights effectively.
- Applying design principles and purposeful color choices.
- Presenting data accurately, transparently, and without misleading the audience.
